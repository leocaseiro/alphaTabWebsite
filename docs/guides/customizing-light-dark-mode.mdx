# Customizing Light and Dark Mode

alphaTab has three different styling layers. Treating them as one thing is the main source of confusion when building a dark theme.

1. **Renderer resources** control the default colors and fonts used by the music sheet.
2. **Data model styles** color individual score, track, bar, voice, beat, and note elements.
3. **CSS** styles the browser-only playback overlays and any player UI you build around alphaTab.

The alphaTabWebsite uses all three. It sets site-wide defaults in `src/environment.ts`, exposes many rendering settings in the playground settings panel, colors individual notes in `src/components/ColoringExample/index.tsx`, and styles playback overlays in `src/css/custom.scss` plus `src/components/AlphaTabFull/styles.module.scss`.

## What alphaTabWebsite Does Today

The website sets the font directory, SoundFont, default player mode, scroll mode, and notation fonts before every `AlphaTabApi` instance is created.

```ts
settings.core.fontDirectory = "/font/";
settings.player.soundFont = "/soundfont/sonivox.sf3";
settings.player.scrollMode = alphaTab.ScrollMode.Off;
settings.player.playerMode = alphaTab.PlayerMode.Disabled;

settings.display.resources.titleFont.families = ["Noto Serif"];
settings.display.resources.tablatureFont.families = ["Noto Sans"];
settings.display.resources.numberedNotationFont.families = ["Noto Sans"];
```

The Docusaurus shell has light and dark color variables, but the switch is disabled in `docusaurus.config.ts`.

```ts
themeConfig: {
  colorMode: {
    disableSwitch: true,
  },
}
```

That means the website defines a dark Docusaurus palette, but does not expose a normal user-facing dark-mode toggle. Also, alphaTab's rendered sheet does not automatically inherit the Docusaurus color variables. You must push theme colors into `settings.display.resources`, into model `style.colors`, or into CSS classes.

## Layer 1: Renderer Resources

Renderer resources are the first place to customize light and dark mode. These affect the default music sheet rendering before you start targeting individual notes.

The playground exposes these color settings:

| Setting path | What it changes |
| --- | --- |
| `display.resources.staffLineColor` | Staff lines |
| `display.resources.barSeparatorColor` | System and bar separators |
| `display.resources.barNumberColor` | Bar numbers |
| `display.resources.mainGlyphColor` | Main notation glyphs |
| `display.resources.secondaryGlyphColor` | Secondary notation glyphs |
| `display.resources.scoreInfoColor` | Title, artist, album, copyright, and other score info text |

Example light/dark resource palette:

```ts
import * as alphaTab from "@coderline/alphatab";

type AlphaTabTheme = {
  sheetBackground: string;
  staffLine: string;
  barSeparator: string;
  barNumber: string;
  mainGlyph: string;
  secondaryGlyph: string;
  scoreInfo: string;
};

const alphaTabThemes: Record<"light" | "dark", AlphaTabTheme> = {
  light: {
    sheetBackground: "#ffffff",
    staffLine: "#979797",
    barSeparator: "#555555",
    barNumber: "#b42f2f",
    mainGlyph: "#111111",
    secondaryGlyph: "#555555",
    scoreInfo: "#222222",
  },
  dark: {
    sheetBackground: "#111318",
    staffLine: "#59606b",
    barSeparator: "#8a94a6",
    barNumber: "#f2b56b",
    mainGlyph: "#f3f5f7",
    secondaryGlyph: "#b7beca",
    scoreInfo: "#e7ecf3",
  },
};

function applyAlphaTabTheme(api: alphaTab.AlphaTabApi, mode: "light" | "dark") {
  const theme = alphaTabThemes[mode];
  const resources = api.settings.display.resources;

  resources.staffLineColor = alphaTab.model.Color.fromJson(theme.staffLine);
  resources.barSeparatorColor = alphaTab.model.Color.fromJson(theme.barSeparator);
  resources.barNumberColor = alphaTab.model.Color.fromJson(theme.barNumber);
  resources.mainGlyphColor = alphaTab.model.Color.fromJson(theme.mainGlyph);
  resources.secondaryGlyphColor = alphaTab.model.Color.fromJson(theme.secondaryGlyph);
  resources.scoreInfoColor = alphaTab.model.Color.fromJson(theme.scoreInfo);

  api.updateSettings();
  api.render();
}
```

You still need CSS for the container background:

```css
.alphaTabSurface {
  background: var(--at-sheet-bg);
}

[data-theme="light"] .alphaTabSurface {
  --at-sheet-bg: #ffffff;
}

[data-theme="dark"] .alphaTabSurface {
  --at-sheet-bg: #111318;
}
```

## Layer 2: Data Model Styles

Model styles are for targeted color decisions. The website's `ColoringExample` sets a `ScoreStyle`, `BeatStyle`, and `NoteStyle`, then calls `renderScore`.

```ts
score.style = new alphaTab.model.ScoreStyle();
score.style.colors.set(
  alphaTab.model.ScoreSubElement.Title,
  alphaTab.model.Color.fromJson("#426d9d")
);

note.style = new alphaTab.model.NoteStyle();
note.style.colors.set(
  alphaTab.model.NoteSubElement.GuitarTabFretNumber,
  alphaTab.model.Color.fromJson("#70ccd6")
);
```

Use this when a color depends on score data, such as fret number, string, track, note duration, difficulty, or validation state.

### Important Runtime Rule

alphaTab does not watch the data model for style changes. If you mutate `score.style`, `track.style`, `bar.style`, `voice.style`, `beat.style`, or `note.style` after rendering, call `api.render()`.

```ts
api.scoreLoaded.on(score => {
  applyModelColors(score, "dark");
});

function switchAlphaTabMode(api: alphaTab.AlphaTabApi, mode: "light" | "dark") {
  applyModelColors(api.score!, mode);
  applyAlphaTabTheme(api, mode);
  api.render();
}
```

### Theme-Aware Model Coloring

```ts
const fretPalettes = {
  light: {
    12: "#bb4648",
    13: "#ab519f",
    14: "#3953a5",
    15: "#007a8a",
    16: "#3d7c23",
    17: "#9a6c00",
  },
  dark: {
    12: "#ff7b7d",
    13: "#f39be8",
    14: "#93a4ff",
    15: "#70ccd6",
    16: "#98e06d",
    17: "#ffd166",
  },
} as const;

function applyModelColors(score: alphaTab.model.Score, mode: "light" | "dark") {
  score.style = new alphaTab.model.ScoreStyle();
  score.style.colors.set(
    alphaTab.model.ScoreSubElement.Title,
    alphaTab.model.Color.fromJson(mode === "dark" ? "#d0e3fa" : "#426d9d")
  );

  for (const track of score.tracks) {
    for (const staff of track.staves) {
      for (const bar of staff.bars) {
        for (const voice of bar.voices) {
          for (const beat of voice.beats) {
            for (const note of beat.notes) {
              const color = fretPalettes[mode][note.fret as keyof typeof fretPalettes.light];
              if (!color) {
                continue;
              }

              note.style = new alphaTab.model.NoteStyle();
              note.style.colors.set(
                alphaTab.model.NoteSubElement.StandardNotationNoteHead,
                alphaTab.model.Color.fromJson(color)
              );
              note.style.colors.set(
                alphaTab.model.NoteSubElement.GuitarTabFretNumber,
                alphaTab.model.Color.fromJson(color)
              );
            }
          }
        }
      }
    }
  }
}
```

## Recommended Light/Dark Integration

In a React app, watch Docusaurus or app theme state, then update alphaTab settings and model colors.

```tsx
import * as alphaTab from "@coderline/alphatab";
import { useEffect } from "react";

function useAlphaTabColorMode(api: alphaTab.AlphaTabApi | undefined) {
  useEffect(() => {
    if (!api) {
      return;
    }

    const apply = () => {
      const mode =
        document.documentElement.dataset.theme === "dark" ? "dark" : "light";

      applyAlphaTabTheme(api, mode);

      if (api.score) {
        applyModelColors(api.score, mode);
      }

      api.render();
    };

    apply();

    const observer = new MutationObserver(apply);
    observer.observe(document.documentElement, {
      attributes: true,
      attributeFilter: ["data-theme"],
    });

    return () => observer.disconnect();
  }, [api]);
}
```

For the initial load, apply model colors in `scoreLoaded` before the first render where possible:

```ts
api.scoreLoaded.on(score => {
  const mode =
    document.documentElement.dataset.theme === "dark" ? "dark" : "light";
  applyModelColors(score, mode);
});
```

## What You Cannot Fully Customize

These are the practical boundaries visible from the website source and public guide behavior:

| Area | Boundary |
| --- | --- |
| Automatic dark mode | alphaTab does not automatically read Docusaurus or CSS theme variables for sheet glyph colors. You must update `display.resources`, model styles, and CSS yourself. |
| Live data model mutations | Changing `score`, `track`, `bar`, `voice`, `beat`, or `note` styles is not observed automatically. Call `api.render()`. |
| CSS access to notation internals | CSS can style playback overlay DOM nodes and SVG highlights. It is not a complete theming API for every notation primitive, especially outside SVG. |
| `.at-highlight` | Only works for SVG rendering in the browser. Use `core.engine = "svg"` if you depend on CSS highlighting. |
| Individual effects | Some effects and annotations are intentionally coarse. For several effect types, the first note or first beat with the effect decides the color. |
| Full player UI | The sidebar, footer, buttons, sliders, video panel, settings panel, and track list are website React/CSS, not built-in alphaTab UI. You can customize them because you own them, but alphaTab will not generate the same shell for you. |
| Background color of the sheet | The rendered glyph colors are alphaTab settings, but the surrounding sheet background is your container CSS. Set both for dark mode. |
| Performance | `api.render()` triggers layout and drawing. Avoid re-rendering on every small UI change such as drag or color picker movement unless debounced. |

## Checklist

For a complete light/dark implementation:

1. Set player shell CSS variables for light and dark mode.
2. Set alphaTab overlay CSS variables for `.at-selection`, `.at-cursor-bar`, `.at-cursor-beat`, and `.at-highlight`.
3. Update `display.resources.*Color` when the mode changes.
4. Update model `style.colors` for score-specific logic when the mode changes.
5. Call `api.updateSettings()` after changing settings.
6. Call `api.render()` after changing rendering settings or model styles.
7. Use SVG if you need `.at-highlight` element coloring.
8. Debounce color picker changes before re-rendering.
